## 🛠 Installation

### Prerequisites

- Power Platform CLI
- Azure DevOps
- Git

### Clone the repository

```bash
git clone https://github.com/username/awesome-power-platform-project.git

cd awesome-power-platform-project
```

### Install dependencies

```bash
npm install
```

## 💻 Usage

### Run locally

npm start

### Run tests
